FILEPREFLIGHT — EXPOSED SECRET RESPONSE CHECKLIST

[ ] Revoke or rotate the live credential first.
[ ] Review access, audit, billing, and security logs.
[ ] Check related permissions, sessions, and dependent systems.
[ ] Follow the organisation's incident, legal, and notification process.
[ ] Remove the value from current files and other copies as required.
[ ] Review Git history, forks, pull requests, logs, notebooks, caches, and generated artifacts with appropriate specialist tools.
[ ] Prepare only the minimum supported file set for AI; use inert placeholders.
[ ] Re-scan the exact prepared files and obtain required approval.

FilePreflight's Windows MVP is planned for supported text, data, configuration, and log extensions. It is not a repository or Git-history scanner.
